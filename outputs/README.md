# Prodigy InfoTech – Data Science Internship

## Task 03: Decision Tree Classifier

### Objective
Build a Decision Tree Classifier to predict whether a bank customer will subscribe to a term deposit based on demographic and behavioral information.

### Dataset
Bank Marketing Dataset – `bank-full.csv`

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

### Project Steps
1. Load and explore the Bank Marketing dataset.
2. Clean the data and handle unknown values.
3. Perform feature preprocessing.
4. Split the dataset into training and testing sets.
5. Build and train a Decision Tree Classifier.
6. Predict customer subscriptions.
7. Evaluate the model using accuracy, precision, recall, F1-score and confusion matrix.
8. Visualize the decision tree and feature importance.

### Model
Decision Tree Classifier with Gini criterion.

### Outputs
- Confusion Matrix
- Decision Tree Visualization
- Feature Importance Chart
- Model Evaluation Report

### How to Run

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

Run:

```bash
python task3.py
```

### Conclusion
This project demonstrates how machine learning and decision tree classification can be used to predict customer subscription behavior using bank marketing data.
